## 15. 임시 처리 · 대본/지시와 다른 부분 · 보고 사항
- **임시**
  - 3층 문제는 임시 풀입니다(5번).
  - 3층 주민 초상화가 없어 1층 「주민」 초상화를 씁니다.
  - 학생과 학교 관계자 초상화는 2층 것을 재사용합니다.
- **연출 판단(확인 부탁)**
  - 「데네브의 말에 카프가 잠시 고개를 돌린다.」는 서술문으로 판단해 나레이션 상자로 보여 줍니다. 별도 고개 돌림 동작은 없습니다.
    - 지문으로 의도하셨다면 대사에서 빼고 동작으로 바꾸겠습니다.
  - 회상 장면 전용 에셋이 없어 2단원 감옥 장면을 조합했습니다. 데네브의 회상 대사 2줄은 회상 화면에서 돌아온 직후에 나옵니다.
  - **카프 방어 자세 이미지는 어드벤처 아카데미 복장입니다.** 그래서 기억이 돌아오기 전인 결계 장면부터 원래 복장으로 보입니다.
    - 해제 때는 원래 복장 standing으로 오른쪽을 봅니다. 안전한 골목에서도 원래 복장입니다.
    - 시대 의상 방어 자세가 필요하면 에셋을 부탁드립니다.
  - 느낌표는 학생과 주민 2명에게만 띄웠습니다.
  - 안전한 골목은 별도 배경이 없어 같은 이벤트 맵의 다른 구간(카메라 오른쪽)을 씁니다.
  - 3층 진행 중 캠프 일반 대화(새 대사를 쓰지 않고 대본 대사를 재사용):
    - 카이든: 진행 중 「(플레이어 이름), 이번에는 주민들의 상황도…」 / 완료 후 「수고했다…」
    - 데네브: 진행 중 「카프가 위험해질 수도…」 / 완료 후 「네. 각자 다음 작전을…」
- **지시와 대본이 다른 부분(지시문을 따름)**
  - 카프 직책: 대본 「정예요원」 ↔ 지시 「부지휘관」 → 부지휘관
  - 보상 제목: 대본 「[다시 맺은 약속]」, 「[업적: 돌아온 동료]」 ↔ 퀘스트 「잊지 않은 약속」, 업적 「돌아온 부지휘관」 → 지시 이름
- **오탈자 · 띄어쓰기(고치지 않음)**
  - 「제가 지킬거예요」 → 지킬 거예요
  - 「아무것도 안했단 말이오」 → 안 했단
  - 「정말이지...끔찍하군요」 말줄임표 뒤 띄어쓰기
  - 「헌병경찰들」(중간 방)과 「헌병 경찰」(골목) 띄어쓰기 혼용
  - 호칭 혼용: 「카이든 경까지…」 / 안전한 골목 「카이든님…」
- **역사 · 내용 확인**
  - 조선총독부 청사(경복궁 앞 건물)는 1916년 착공, 1926년 완공입니다.
    - 1910년대 초에는 아직 없었고, 총독부는 남산 왜성대 청사를 썼습니다.
    - 「경복궁 앞을 가로막고 있는 저 건물」 장면을 1910년대 초로 보면 시기가 맞지 않습니다.
  - 농민 방: 「땅 주인은 따로 있고 우리는 농사를 짓는 처지요」(소작농)와 「내 땅을 가져가질 않나」, 「내 땅이었던 곳은…」(자작농)이 한 인물 안에서 엇갈립니다.
- **첨부 파일 이름 오타**
  - `현병 초상화.png`(→ 헌병)
  - `escpae map_*.png`(→ escape)
