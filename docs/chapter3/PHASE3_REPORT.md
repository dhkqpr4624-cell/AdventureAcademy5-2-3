|---|---|---|
| BGM(HQ) RMS 평균 / p95 / peak | −38.6 / −34.9 / −22.4 | 변화 없음 |

## 3. 보급물품 비상 지원

### 판정 순서
1. 목표 층을 정합니다. 수락했고 아직 마지막 방을 끝내지 않은 3단원 층(2층 → 1층 순)입니다. 없으면 지원하지 않습니다.
2. 기대 피해를 계산합니다. 정답률은 70%입니다.
   - 실제 층 생성기(`createDungeonRun` + 층별 `prepareMap`)로 고정 시드 9개를 만들고, 그 중앙값 시드를 씁니다.
   - 기준 경로: 시작방에서 아직 필요한 방(메인루트 전투방, 남은 스토리방, 마지막 방)까지의 최단경로 합집합입니다. 선택 방은 넣지 않습니다.
   - 전투 1회 기대 피해: 실제 턴 규칙으로 모든 정답/오답 조합을 열거해 계산합니다.
     - 마지막 문제 뒤에는 전부 맞혔으면 적의 턴이 없습니다.
     - 오답 피해 29, 일반 9, 엘리트 12. 문제 수는 일반 2개, 엘리트 3개입니다.
     - 일반 전투 = **25.59**, 엘리트 전투 = **47.18**
   - 함정방: (1 − 0.7) × 실제 함정 피해
   - 현재 기준 경로:
     - 1층: 일반 3 + 엘리트 1 → **123.95**
     - 2층: 일반 3 + 엘리트 1 + 함정 1 → **126.95**
3. 필요 회복량 = ceil(기대 피해 − (현재 HP − 1))
4. 확보 가능한 회복량 = 보유 포션(소형 20, 중형 35) + 현재 골드로 상점 가격(소형 8G, 중형 14G)에 살 수 있는 최대 회복량. 주머니 용량 안에서만 셉니다.
5. (4)가 (3)보다 작을 때만 지원합니다.
   - 지급량 = min(ceil(부족분 / 20), 구매 후 남는 소형 포션 칸)
   - 즉 부족분을 채우는 최소한의 소형 포션입니다.

### 연출
1. 대사 시스템으로 3줄을 보여 줍니다.
2. 포션을 지급하고 기존 회복 효과음(`heal-sfx`)을 재생합니다.
3. "보급 물품 획득 — 소형 회복 포션 N개" 팝업을 띄웁니다.
4. 기존 상점을 엽니다.
- 지원 조건이 아니면 기존처럼 상점이 바로 열립니다.

### 악용 방지
- 지급 직전에 최신 상태로 다시 판정합니다.
- 받은 포션도 보유량에 포함되므로, 연타·재클릭·안 쓴 상태에서의 재요청에는 0개가 나옵니다.
- 대사 도중 새로고침하면 아무것도 지급되지 않고, 다시 클릭하면 처음부터 다시 진행합니다.
- 지급 기록은 세이브에 `unit3-emergency-supply:<층>:grant-<n>` 플래그로 남습니다.
- 실패한 런에서 포션을 다 쓰면 새 상태로 다시 판정하므로, 영구 잠금은 없습니다.
- 주머니 용량을 넘기지 않으므로 무한 포션이나 골드는 생기지 않습니다.

  - 40개 시드 레이아웃과 6가지 순서, 1층 배치 불변
  - 퀘스트 흐름, 보상 1회, 세이브 왕복
  - 비상 지원 케이스
- **빌드 — 대체 빌드임을 밝힙니다.**
  - npm 접근이 막혀 있어 `vite build`는 실행하지 못했습니다.
  - 대신 `scripts/local-esbuild-build.mjs`(esbuild 번들, base `/AdventureAcademy5-2-3/`)로 만든 결과물로 브라우저 테스트를 했습니다.
  - 실제 Vite 빌드와 Pages 배포는 사용자 확인이 필요합니다.

### 브라우저(Playwright, 대체 빌드)
- 2층 전체 실주행 B (스토리 순서 3→2→1, 선택지 ②), 모두 통과:
  - 퀘스트 거절 → 수락
  - 미수락 상태에서 입구를 누르면 안내
  - 트래커, 층 표기 "던전 2층", 세이브의 현재 층
  - 1회 패배 → 다시 도전
  - 마지막 방 → 캠프 복귀
  - 보상, 업적 카드 2장, 층 선택 팝업
  - 새로고침 후 중복 없음
- 2층 실주행 A (순서 2→1→3, 선택지 ①):
  - 시작, 학교 전투, 스토리 3개, 이후 대화 1회까지 통과했습니다.
  - 마지막 방으로 가는 이동에서 스크립트가 중단되었습니다(반복 패배로 추정).
  - 그래서 마지막 방은 "스토리 3개 완료" 세이브에서 따로 확인했습니다: 카프 fade, 정적, 선택지, 카프 퇴장, 플래그 기록.
- 방문 순서별 실주행 (2층, 스토리방 1=교실 / 2=모금 / 3=하얼빈 소식). 6가지 순서를 모두 실제로 돌렸습니다:

| 순서 | 결과 |
|---|---|
| 3→2→1 (실주행 B) | 통과 |
| 2→1→3 (실주행 A) | 통과 (이후 대화 1회까지) |
| 1→2→3, 1→3→2, 2→3→1, 3→1→2 | 통과. 첫 방은 세이브로 완료한 뒤 나머지 두 방을 주행했습니다. |

  - 모든 순서에서 각 스토리는 1회만 재생되었습니다.
  - 3개를 마친 뒤의 대화도 정확히 1회였습니다.
  - 시작 이벤트는 다시 재생되지 않았고, 콘솔 오류도 없었습니다.
- 보급물품: 위 3절의 표
- 무기와 몬스터 VFX:
  - 환도, 만년필, 지팡이별 무기 VFX
  - 아부쟁이 공격 / 처치 검은 연기, 밀고 그림자 안개, 이토 망령 폭발이 모두 실제로 재생되었습니다.
  - 콘솔 오류와 404는 없었습니다.
- 세이브 호환:
  - 기존 1층 세이브 7종이 모두 정상 로드되었습니다: 미수락 / 수락 / 수레 완료 / 스토리 완료 / 층 완료(복귀 컷신) / 완료 / 환도 장착.
  - 2층 세이브 3종(수락 / 일부 진행 / 마지막)도 정상입니다. 재입장해도 이미 본 이벤트는 재생되지 않습니다.
- 1층 회귀 (새 빌드):
  - BGM 전체 흐름 테스트 PASS: 인트로 → 워프 → 베이스캠프 → 상점 → 1층 입장/복귀 → 이어하기·새로고침.
  - 인트로와 도착 장면 스킵 테스트 PASS: HQ BGM이 끊기지 않고 페이드되고, 베이스캠프 BGM은 1회만 재생됩니다.
  - 1층 스토리 순서 주행(2→1→3) PASS: 이후 대화 1회, 수레 이벤트 재생 없음.
  - 오디오 요청 실패나 콘솔 오류는 없었습니다.

## 11. 미완료 · 임시 · 편차
- **임시**
  - 2층 문제 풀: 1층 임시 풀을 복사했습니다. 역사 문제를 새로 만들지 않았습니다.
  - 밀고하는 그림자 이미지: 미제공이라 1층 그림자 이미지를 재사용했습니다.
  - 업적 아이콘: 미제공이라 ★ 메달을 썼습니다.
- **기존 에셋 대체**
  - 외침과 발소리: 기존 효과음 중에 맞는 것이 없어 Web Audio로 절차 생성했습니다(`playDistantShout`, `playFootsteps`).
  - 아이템 획득 효과음: 전용 효과음이 없어서 기존 `heal-sfx`를 재사용했습니다.
- **해석이 들어간 연출**
  - 마지막 방에서 카프 스탠딩이 fade in 되는 시점: 지문이 모호해서 카프의 첫 대사 시점으로 정했습니다.
  - 아부쟁이 친일파의 초상화: 별도 초상화가 없어 몬스터 이미지를 썼습니다.
  - 데네브의 sad / smile / serious 표정: 해당 초상화가 없어 기본 초상화로 표시했습니다.
  - 카프 초상화: 시대 의상 초상화가 없어 기존 카프 초상화를 썼습니다. 스탠딩만 시대 의상입니다.
  - 마지막 선택지에서 초상화가 숨겨지는 것은 기존 대사 시스템의 동작입니다.
- **UI 추가**
  - 1층과 2층을 모두 열 수 있게 되면, 입구를 누를 때 층 선택 팝업이 뜹니다.
  - 2층을 수락하기 전에는 입구에서 「데네브와 먼저 이야기해 보세요.」 안내가 나옵니다.
- **대본 오탈자·모호점** (대사는 원문 그대로 두었습니다)
  - 「학교 뒷길를」: 지문의 파일명이라 화면에는 나오지 않습니다.
  - 「[선택지 분기 합류]|」 뒤의 `|`: 무시했습니다.
  - 「말만 하는군요!」: 앞쪽 공백이 빠져 있습니다.
  - 「하고 있는거예요」: 띄어쓰기상 「하고 있는 거예요」가 맞습니다.
  - 「준비중」: 띄어쓰기상 「준비 중」이 맞습니다.
  - 「이토 히로부미..」, 「이곳은..」: 말줄임표 점이 2개입니다.
  - 「스토리 이벤트 방 1 최초 입장 시」 제목 중복: 이벤트 하나로 만들었습니다.
  - 고칠 문구를 알려 주시면 그대로 반영하겠습니다.
