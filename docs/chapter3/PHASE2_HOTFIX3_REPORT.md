## 1. PixelFX 사용 여부 (먼저 확인)

- **PixelFX로 VFX를 만들지 못했습니다.** 대체 방법(Python·SVG·Canvas 등)으로도 만들지 않았습니다.
- 확인 내용:
  - PixelFX(`patch-gg/pixelfx` 0.3.1, 커밋 `5294518`)는 읽기 전용으로 받을 수 있었습니다.
  - 설치 없이 Node만으로 동작하는 구조이고, `melee/sword-slash` 등 검 베기 이펙트가 들어 있습니다.
  - 이 세션에 PixelFX MCP 도구는 없습니다.
- 실패 원인:
  - 렌더 명령(`node tools/render.mjs melee/sword-slash --sheet`)이 이 환경의 자동 권한 검사기에 거부되었습니다. 외부에서 받은 코드 실행을 막은 것으로, Phase 2 때와 같은 원인입니다.
  - 우회는 시도하지 않았습니다.
- 준비해 둔 것 (지금은 게임 동작에 영향 없음):
  - `UIBYEONG_HWANDO_SLASH_VFX` 정의를 추가했습니다(`src/game/combat/attackVfxDefinitions.ts`).
  - 전투 화면의 무기 VFX 분기와 CSS 클래스(`.weapon-hwando-slash-vfx`)를 추가했습니다.
  - **의병의 환도에는 아직 `attackVfxId`를 연결하지 않았습니다.** 시트 없이 연결하면 404가 나기 때문입니다. 그래서 지금 환도로 공격하면 이전과 같은 기본 VFX가 나옵니다.
- 시트 규격 (기존 무기 VFX 시스템을 조사해 정한 값):

| 항목 | 값 (기존 무기 VFX와 동일) |
|---|---|
| 프레임 크기 / 시트 크기 | 100×100 / 800×100, 투명 PNG |
| 배열 / 프레임 수 | 가로 1줄 / 8프레임 |
| FPS / 재생 시간 | 8fps / 1초, 1회 재생 후 종료(`steps(8) 1 both`) |
| 화면 표시 | 800×800 pixelated, 몬스터 중심(`translate(-50%, calc(-89.75% + 50px))`), z-index 18 |
| 타이밍 | 정답 처리 후 `playEquippedWeaponVfx()` → 1초 뒤 숨김 → 기존 피해 처리. 피해량·턴·SFX 변화 없음 |
| 무기별 적용 | 장착한 `weaponSkin`의 `attackVfxId`만 재생. 소유만 하면 미적용, 교체 즉시 반영, 저장된 장착 상태 그대로 사용, 기본 VFX와 동시 재생 없음 |

- PixelFX를 실행할 수 있게 되면 할 일:
  - `public/assets/combat/vfx/uibyeong-hwando-slash.png`(800×100)를 렌더합니다.
  - 아이템에 `attackVfxId: "uibyeong-hwando-slash"` 한 줄을 추가하고 브라우저에서 검증합니다.
