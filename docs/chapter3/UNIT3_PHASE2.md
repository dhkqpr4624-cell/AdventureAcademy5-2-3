## 1. 공통 수정
- **지난 이야기(줄거리) 대사창**: 3단원 내레이션 상자가 대사창 전체 폭을 쓰고, `다음` 버튼 전용 공간을 확보해 글자와 겹치지 않음(데스크톱·모바일 반응형, `word-break: keep-all`).
- **플레이어 이름 강조**: `(플레이어 이름)`, `(플레이어이름)`, `{{playerName}}` 자리표시자만 구조화 토큰으로 바꿔 강조. 이름 `지지`가 `흩어지지` 안에 있어도 강조되지 않음. 강조 스타일(`.story-player-name`)은 그대로.
- **플레이어 미표시**: 작전본부·던전 도착·베이스캠프·던전 어디에도 플레이어 스프라이트/실루엣/초상화를 그리지 않음(1인칭 무기만 유지). Phase 1 핫픽스에서 남아 있던 `player-standing.png`, `make_player_silhouette.py` 삭제.

## 2. 캐릭터 에셋
- 카이든·루나·테오 standing L/R + blink L/R(4프레임, 600×700)을 ZIP 버전으로 교체(`src/assets/story/npcs/chapter3/…`). 인트로 무대와 베이스캠프 카이든에 적용, 대기 중 무작위 간격 눈 깜빡임.
- 인트로 연출: 카이든 첫 등장 `standing_L`, 연구원 등장 시 데네브·카이든 `standing_R`, “…그 이야기는 하지 않으셔도 됩니다.” / “아론, 자네까지 그러는 건가.” `shame` 초상화. 새 프레임 폭에 맞춰 작전본부 대열 간격 조정(겹침 없음 — 검사 포함).
- **PixelFX**: 이 환경에서 실행이 허용되지 않아(자동 승인 거부) 걷기/대기 시트를 생성하지 못함. 미생성: 카이든 walk_L/R, 루나 walk·idle L/R, 테오 walk·idle L/R. 늘이기·이름 바꾸기로 대체하지 않았고, 카이든 정찰 이동은 standing 프레임이 미끄러지듯 이동(작은 상하 흔들림)하도록 처리. 아론 에셋은 제공되지 않아 변경 없음.

## 3. 스토리 건너뛰기
- 3단원 인트로 재생 중 `처음 화면` 옆에 `건너뛰기`. 끝까지 본 것과 같은 완료 플래그·저장 후 베이스캠프로 이동.
- 던전 1층 이벤트(시작방, 짐수레 전·후, 스토리 방 1~3, 세 이벤트 후 대화, 마지막 방, 베이스캠프 귀환, 퀘스트 완료)는 `건너뛰기` 시 해당 플래그를 그대로 기록. 짐수레 전투 전 대사를 건너뛰어도 전투는 반드시 진행. 퀘스트 수령 대화는 선택지가 결과를 정하므로 건너뛰기 없음.

## 4. 베이스캠프
- 데네브·카이든·보급물품·던전 입구 클릭 가능: 마우스를 올리면 흰색 픽셀 외곽선 + 포인터 커서, 클릭 영역은 PNG의 실제 그림 영역에 맞춤. 키보드 포커스 시에도 같은 외곽선이 나오도록 구현(키보드 조작은 별도 테스트하지 않음).
- 베이스캠프에서만 좌하단 HP 바 숨김(던전에서는 그대로).
- **보급물품**(`shop npc.png`, 새 상점 주인/일러스트/아이템 없음): 2단원 `ShopPopup`·인벤토리·골드 로직 그대로. 판매 목록 = 기존 `SHOP_PRODUCTS` 그대로 — 소형 회복 포션, 중형 회복 포션, 소형 포션 주머니 확장(100G, 최대 2), 중형 포션 주머니 확장(200G, 최대 1).
- 인벤토리(의병의 환도 장착)·업적 버튼 추가(기존 UI 재사용).

## 5. 던전 1층 「빼앗긴 외교권, 꺼지지 않는 의지」 / 퀘스트 「돌아갈 곳을 잊은 사람」
- 몬스터: `먹물 든 을사늑약 문서`(일반 A, 짐수레 전투), `밀고의 그림자`(일반 B), `통감부 감시자`(정예). 공격 VFX 3종은 PixelFX 대신 `scripts/chapter3/make_floor1_monster_vfx.py`로 절차적 생성(먹물 튐 / 그림자 등불탄 / 군도 베기). 전투 로직·피해량·타이밍은 그대로.
- 구조: 시작방 → (유일한 출구) 짐수레 방(필수 전투) → 곁가지 막다른 길의 스토리 방 3곳(순서 자유, 1회, 저장) → 마지막 방(전투 없음). 세 이벤트 전에 마지막 방으로 가면 “아직 살펴보지 않은 곳이 있다.” 안내.
- 대사: `docs/chapter3/floor1-original-script.txt` 원문 그대로(검사로 대조). 오버라이드: 짐꾼/민수 standing·스프라이트·베이스캠프 NPC·전용 대화 없음(대화창 초상화만), 베이스캠프 최초 귀환은 짧은 내레이션, 민수 상시 대화 제거.

## 6. 1900년대 경성 3D 환경
- 제공 FBX → `scripts/chapter3/convert-gyeongseong-fbx.mjs`(Playwright + FBXLoader)로 작은 바이너리 메시(GSM1) + 1024px 베이스컬러 JPEG로 변환(`public/assets/chapter3/gyeongseong`). 원본 FBX는 배포하지 않는 `art-source/chapter3/gyeongseong`에 보관(12a 포함).
- 방 = 10×10 광장, 연결 = 폭 6 거리(2 단위 격자). 직선·코너·T자·교차·막다른 길이 던전 그래프에서 그대로 만들어짐. 건물은 도로를 향해 배치, 던전 밖 골목은 건물/벽으로 막아 틈 없음. 던전 시드로 결정적 배치.
- 도로: 07b 전차 선로(주 경로 거리 중앙), 07b에서 레일을 뺀 일반 포장, 07a 연석(막힌 쪽으로 회전). **12a-cracked-road는 1~7층에 절대 사용하지 않음**(파일은 보관, 회귀 검사 포함).
- 하늘 돔 셰이더, 안개, 반구광+태양광. 카메라 이동·내비게이션·미니맵·무기·전투 전환은 변경 없음.
- 성능: 모델별 지오메트리/머티리얼 1개 + InstancedMesh, 도로 정점색 굽기(타일 종류당 1 드로우콜), 카메라 주변만 상세 도로(LOD), 화면 종료 시 전부 dispose.
